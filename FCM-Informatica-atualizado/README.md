# FCM Informática — site

Site institucional responsivo feito em HTML, CSS e JavaScript puro.

## Como visualizar

Abra `index.html` no navegador ou publique o conteúdo desta pasta em qualquer hospedagem estática.

## Estrutura

- `index.html`: conteúdo, SEO básico e links de contato.
- `src/styles/styles.css`: layout, responsividade e animação do carrossel.
- `src/javascript/script.js`: menu mobile e ano automático do rodapé.
- `src/images/`: imagens em WebP otimizadas.

## Observações

- O carrossel de serviços roda continuamente, pausa ao passar o mouse ou focar um link e respeita a preferência de movimento reduzido do sistema.
- Os links de orçamento direcionam para o WhatsApp informado no projeto.
- Revise preços, área de atendimento e depoimentos antes de publicar. Os valores antigos não foram mantidos como preços fixos para evitar divulgar informações desatualizadas.
